# Broadway Betties language rule

Use **Betties** for every brand reference.

- Never use `Bettie`.
- Never use `Bettie's` or `Betties'`.
- Possessiveness and ordinary grammar do not change the spelling.
- Only use a different form when the client explicitly requests an exception.

This rule applies to visible copy, metadata, accessibility text, form messages, captions, labels, and future content.
